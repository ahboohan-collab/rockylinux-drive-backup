Privacy Policy

Last updated: October 22, 2026

About the Application

RockyLinux Drive Backup is a privately operated application using rclone to back up data from a Linux server to the owner's Google Drive.

Google Drive Data Access

The application accesses the Google Drive account authorized by its owner to upload, list, verify, restore, and manage backup files.

Data Storage and Security

Backup files are intended to be encrypted locally before upload using rclone crypt. Google OAuth credentials are stored privately on the server and are not published on this website.

Data Sharing

The application does not sell or share Google user data with advertisers or unrelated third parties. Data is transferred to Google Drive for the purpose of backup and recovery.

Data Retention and Deletion

Backup files are retained according to the owner's backup policy and may be deleted by the owner. Google account access can be revoked through Google Account settings.

Contact

For questions about this application's privacy practices, contact the application administrator using the support email displayed on its Google OAuth consent screen.
